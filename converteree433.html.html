Where power electronics sits

Electronics splits by power level: analog (0–15 V), digital (logic 0–5 V), and power (kA–kW). Power electronics converters are classified by what they convert between:

The Power Electronics Interface (PEI)

A PEI supplies power based on load requirements, accepting AC or DC input and delivering AC (variable or fixed) or DC (fixed or variable/high) output, governed by a control block. A power electronics converter has three jobs:

Process  ·  Regulate  ·  Offer stabilitythe three functions of every PE interface
  1. Process — supply power based on load requirements.
  2. Regulate — hold the output power/voltage steady.
  3. Stabilise — offer stability to the system to a certain extent.

SMPS: two operating modes

Continuous Conduction Mode

Inductor current never reaches zero within a switching cycle. Steady-state analysis of all fundamental DC-DC converters is carried out here first.

Discontinuous Conduction Mode

Inductor current starts and ends each cycle at zero. The converter begins behaving like a linear converter (unlike CCM) — this helps control transients and improves stability (faster restoration of the steady-state operating point).

Both modes are analysed for two categories: non-isolated and isolated (galvanic). Dynamic analysis on top of this helps design the controller logic and feedback loops.

Characteristics of an ideal converter

  1. Input ≈ output; efficiency η ≈ 100%
  2. Output voltage should follow the reference input
  3. All converters must behave like a voltage source
  4. Should have minimum distortion
  5. Should have good dynamic performance

B · Linear Regulator

A MOSFET is operated in its saturation region so its internal (channel) resistance adjusts continuously, making Vo track Vref. Because the pass device dissipates the difference as heat, dynamic performance and efficiency are both poor.

Vo = VrefR₁+R₂R₂
C · Charge Pump

Also called a voltage-doubler circuit. Cf is the flying/floating capacitor, C2 the reservoir capacitor. Two intervals alternate: interval 1 charges Cf to Vin; interval 2 puts Vin+Cf in series to charge Vo to 2Vin.

D · SMPS: the switch-then-filter idea

An SPDT switch alternates the node Vx between Vin and 0; a low-pass filter then extracts the DC average with minimum distortion.

⟨vx⟩ = ⟨vo⟩ = (1/Ts) ∫0Ts vx dt
    = (1/Ts) [ ∫0DTs vin dt + ∫DTsTs 0 dt ]
    = D·Vin
Vo = D·Vin     D = Ton/T

Replacing the second SPDT position with a diode (S₂ → diode) gives the practical buck converter — semiconductor devices give very low switching loss and negligible on-resistance, so this configuration satisfies all five ideal-converter conditions.

02

Steady-State Analysis — CCM

non-isolated

Every DC-DC converter is analysed with two fundamental principles. The order of a converter equals its number of passive (energy-storing) elements.

1 · Inductor volt-second balance

vL = L·diL/dt. If ⟨diL⟩Ts ≠ 0, the inductor saturates — H ∝ iL runs away, and a saturated inductor draws as much current as it can while the source keeps supplying it ("inductor boom"). So in steady state:

VL·D + VL′·D′ = 0
2 · Capacitor charge-second balance

ic = C·dvc/dt. If ⟨dvc⟩Ts ≠ 0, the capacitor overcharges indefinitely ("boom"). So in steady state:

ic·D + ic′·D′ = 0

Buck converter

Case 1 · S on, D off (DTs)
vL = Vin − Vo
ic = iL − io
Case 2 · S off, D on (D′Ts)
vL = −Vo
ic = iL − io

Applying volt-second balance:

(Vin − Vo)·D·Ts + (−Vo)·D′·Ts = 0
⇒ D·Vin − (D+D′)Vo = 0
Vo = D·Vinvoltage gain Av = Vo/Vin = D — a straight line, so buck is called the linear converter

Charge-second balance gives (iL−io)(D+D′) = 0 ⇒ IL = Io. Average current through S is D·IL, through the diode D′·IL.

ΔiL = Vin−VoL · D·Ts,   ΔVLVc = 1−D8LCf2
Design note

Replacing the diode with an active switch gives a synchronous buck — a bidirectional topology allowing much higher current, since a MOSFET has lower on-resistance than the voltage drop across a diode (also reduces heat loss). Common in microprocessor power supplies.

Boost converter

Duty ratio D now defines the fraction of the cycle the switch shorts the inductor to ground, forcing energy into it; when the switch opens, the diode routes that energy to the output.

Av = Vo/Vin = 1/(1−D)    IL = Io/(1−D)non-linear

As D → 1 the gain diverges — in practice, parasitic resistance in L and the switch makes the real curve fold over and Vo actually drops at very high D, so boost duty ratio is restricted to about 0.1–0.8 in practice.

Buck-boost converter

Take the buck and boost topologies and connect them in cascade (feeding one's output stage into the other's input stage). The two topologies each present a voltage-stiff node (a capacitor) in parallel — connecting two voltage-stiff elements directly has no circuit-physics meaning, so the redundant, non-switching capacitor is removed and the two inductors merge:

L = L₁ + L₂   (since neither inductor's state changes across a switching instant — no impact on steady-state operation, so it's redundant and can be removed)
Ton: vL = Vin,  io = −ic
Toff: vL = −Vo,  iL = ic + io
Volt-sec: Vin·D + (−Vo)·D′ = 0
Vo = −D1−DVin    IL = Io1−D    Av = D1−D output polarity is inverted (−ve sign handled by circuit orientation)

Ćuk converter

Replace the buck-boost's SPDT node with an SPST switch, add a transfer capacitor C₁ between the two inductors, and a diode — this is the Ćuk converter: a 4th-order converter (two inductors, two capacitors) that keeps its opposite output polarity.

State 1 — S closed (DTs):   vL1=Vin,   vL2 = −vC1−Vo,   iC1=−IL2=−Io,   iC2=IL2−Io
State 2 — S open (D′Ts):   vL1=Vin−vC1,   vL2=−Vo,   iC1=IL1=Iin,   iC2=IL2−Io

Volt-sec (L₁): Vin·D + (Vin−VC1)(1−D) = 0  ⇒  VC1 = Vin/(1−D) …(1)
Volt-sec (L₂): (−VC1−Vo)D + (−Vo)(1−D) = 0  ⇒  Vo = −VC1·D …(2)
Sub (1) → (2): Vo = −(Vin/(1−D))·D
Vo/Vin = −D/(1−D)     Io/Iin = (1−D)/D non-linear, same gain shape as buck-boost

03

Discontinuous Conduction Mode

DCM

As output/load current is reduced, the inductor current ripple stays the same size while its average shrinks — eventually the current tries to go negative. An uncontrolled unidirectional device (a diode) cannot carry reverse current, so iL clamps at zero until the next switching cycle begins. Not every converter can enter DCM — replacing the diode with a bidirectional switch (synchronous topology) removes DCM entirely.

DCM entry condition:   ΔiL/2 > ILpeak-to-peak ripple exceeds twice the average current

Buck converter in DCM

Three intervals per cycle instead of two:

IntervalDurationvLState
1DTsVin−VoS on, D off
2D₁′Ts−VoS off, D on (freewheeling)
3D₂′Ts0both off, iL=0
V-sec: D(Vin−Vo) + D₁′(−Vo) = 0  ⇒  Vo = DD+D₁′Vin …(1)  (D₁′ unknown — found from when iL hits 0)

Peak iL: ipk = (Vin−Vo)DTs/L
Io = ⟨iL⟩ = area under iL curve ⇒ ⟨iL⟩Ts = ½·ipk·(D+D₁′)
From (1): D+D₁′ = DVin/Vo  ⇒  Vo/R = ½·[(Vin−Vo)D/L]·DTs·DVin/Vo
Vo/Vin = 21+√(1+4K/D²)     K = 2L/(RTs) DCM gain curve sits below the CCM straight line Vo=DVin, and bends toward it as K↓

Buck-boost / Ćuk in DCM — the CCM/DCM boundary

Setting ⟨iD⟩=Io exactly at the boundary of DCM gives:

½·ipk·(D₁′Ts/Ts) = Vo/R,   ipk=VoD₁′Ts/L
⇒ D₁′² = 2L/(RTs) = K  ⇒  D₁′ = √K
Voltage gain in DCM = D/√K    linear in D
ModeGain Vo/VinCharacter
CCMD/(1−D)non-linear
DCMD/√Klinear

This is why a buck-boost is sometimes deliberately operated in DCM: it simplifies control-loop design by turning a non-linear plant into a linear one.

Boundary condition (CCM ↔ DCM):   D′² = 2L/(RTs) D′² > 2L/RTs → DCM  ·  D′² < 2L/RTs → CCM

Ts and L are the two parameters the designer controls to stay in the desired mode.

Isolated Topologies

galvanic isolation

Why leave non-isolated converters behind?

DisadvantageWhy it matters
Common groundInput and output share a ground — no galvanic isolation. Disturbances on one side directly affect the other.
Extreme duty ratiosTheoretically 0<D<1, but practically D is restricted to 0.1–0.8. In boost converters, D>0.8 causes output voltage to drop due to parasitic resistance, limiting wide-range regulation.
Single output onlyNo provision for multiple outputs.
Fixed polarityPhase/polarity reversal is fixed and cannot easily be changed.
The fix — insert an isolation transformer
  1. Enables separate ground references for primary & secondary (galvanic isolation)
  2. Turns ratio handles large step-up/down without extreme duty ratios
  3. Secondary tappings can provide multiple output rails
  4. Changing the transformer dot convention gives polarity flexibility freely

Why a transformer can't just be dropped in

An inductor's node switches between states almost like AC — attaching a transformer there seems natural, provided the dot convention keeps S and D turning on together. But testing volt-second balance on the magnetising inductance LM reveals the problem: while S is on, current ramps up (Vin/LM slope); while S is off, no reverse voltage is applied — so iM only keeps climbing. LM saturates and blows up. A negative voltage during the off-time is required to reset the flux — this is what every isolated topology below provides, each in its own way.

Full-Bridge Buck Converter

Three operating modes per half-cycle (the fourth repeats the second):

ModeDevices oniLm behaviour
AQ₁,Q₃ + D₁Ramps up
BAll off, D₁D₂ freewheelFlat (off)
CQ₂,Q₄ + D₂Ramps down
Vo/Vin = nDD = fraction of the period either diagonal pair is on; D′ = all switches off
AdvantageDisadvantage
Vo and Vin have different groundsComplex control logic; gate driver must keep intervals A and C exactly equal or the transformer saturates

Half-Bridge Converter

To counter the cost of four switches, split the input DC bus with two capacitors (each holding 0.5Vin) and drive the transformer with just two complementary switches. Never let both switches be on together (shoot-through).

Vo/Vin = 0.5·n·D   (0.5D for 1:1)

Control is simpler (only two complementary switches) — typically used below ≈750 W–1 kW, lower power rating than full bridge.

Forward Converter

Controller cost dominates converter cost, so the next step is to reduce switch count to one, at the cost of extra transformer windings (three: primary, secondary, tertiary/reset) and extra diodes.

S₁ on: D₁,D₃ off, (n₃/n₁)Vin appears across the tertiary winding
S₁ off: D₂ off; D₁ turns on to reset flux in the magnetising circuit; D₃ conducts due to iL ⇒ −(n₁/n₂)Vin appears across the winding

V-sec: D·Vin = D₂·Vin(n₁/n₂)  ⇒  D₂ = D·n₂/n₁
D + D₂ + D₃ = 1,   D₃ = 1 − D − D·n₂/n₁ ≥ 0
D ≤ 1/(1+n₂/n₁)   → with n₂=n₁:   Dmax ≤ 0.5 if D>50%, the transformer saturates and inrush current flows — the defining limitation of the forward converter

Isolated Flyback Converter

Start from the non-isolated buck-boost and split its single inductor into a coupled transformer winding set. The naive version leaves the switch floating (both terminals connected to power-carrying nodes) — the fix is to re-orient the winding so the switch has one terminal grounded, which makes the gate-driver design trivial.

V-sec: D·Vin + D′(−Vo·n₁/n₂) = 0
Vo/Vin = (D/D′)·(n₂/n₁)
ProsCons
Switch has one grounded terminal → very easy gate drive. Only one diode required — one of the most popular converter topologies.Non-linear topology — designing its control loop is difficult.

Isolated Boost & Isolated Ćuk

An isolated boost places the H-bridge after the boost inductor, feeding either a centre-tapped secondary (simpler, but diode PIV rating doubles that of a full-bridge secondary — less cost-effective) or a full-bridge secondary (better diode utilisation, more switches).

05

Dynamic (Small-Signal) Modelling

control design

Whether the converter uses a linear regulator or a switching regulator, a feedback loop is required to hold Vo at Vref. Designing that loop requires knowing the converter's dynamic behaviour, not just its DC operating point.

A gate driver (GD) is always needed as the interface between the duty cycle d generated by the PWM and the switch — the PWM itself cannot drive the gate directly.

Perturbation and small-signal disturbance

In small-signal modelling, a sinusoidal perturbation is added to a variable: d(t) = D + D̂msinωt. Perturbing D disturbs every other quantity — iL, vL, ic, Io — until the system re-settles. There are two classes of disturbance:

  • Small-signal disturbance — what the feedback loop is designed for.
  • Large-signal disturbance — faults and other large transients, which feedback alone cannot control.
Control-to-output TF   Gc(s) = v̂o(s)/d̂(s)  |v̂in=0 d is the control variable that moves Vo

Buck converter — full derivation

  • State equations per interval. DTs: vL=vin−vo, ic=iL−io. D′Ts: vL=−vo, ic=iL−io.
  • Average over one switching period.
    ⟨vL⟩Ts = (vin−vo)d + (−vo)d′ = d·vin − vo
    ∴ L d⟨iL⟩/dt = d·vin − vo …(1)

    ⟨ic⟩Ts = iL−io  ⇒  C dvc/dt = iL − vo/R …(2)
  • Perturb: d=D+d̂, vo=Vo+v̂o, vin=Vin+v̂in, iL=IL+îL.
    From (1): L dîL/dt = D·v̂in + d̂·Vin + d̂·v̂in − v̂o
  • Linearise (drop 2nd-order small-signal terms, e.g. d̂·v̂in):
    L dîL/dt = D·v̂in + d̂·Vin − v̂o …(3)
    C dv̂o/dt = îL − îo …(4)
  • Laplace transform (conventional method — the alternative is state-space averaging):
    Ls·îL(s) = D·v̂in(s) + d̂Vin − v̂o(s) …(6)
    Cs·v̂o(s) = îL(s) − v̂o(s)/R  ⇒  îL(s) = Cs·v̂o(s) + v̂o(s)/R …(7)
  • Combine & extract the transfer function (setting v̂in=0):
    LCs²v̂o(s) + (LC/R)s·v̂o(s) + v̂o(s) = d̂·Vin
    • v̂o(s)/d̂(s) |v̂in=0 = VinLCs² + (LC/R)s + 1 buck control-to-output transfer function — a 2nd-order low-pass response

    Other transfer functions of interest from the same state equations: îL/d̂ (at v̂in=0), and the audio susceptibility v̂o/v̂in (at d̂=0), and îL/v̂in (at d̂=0).

    Boost converter

    Steps: (1) state equations → (2) average → (3) perturb the averaged equations → (4) Laplace transform → (5) extract the transfer function. Carried out the same way as the buck (do-it-yourself), the result is:

    v̂o(s)/î(s) = R(1−d)² − sLs²RLC + sL + R(1−d)² note the right-half-plane zero — a hallmark of boost-derived converters

    Compensator Design

    error amplifier

    A compensator shapes the loop gain to achieve suitable gain margin (GM) and phase margin (PM). Three standard types are used, in increasing order of complexity.

    Type I — single pole at origin
    Gc(s) = k/s

    Op-amp integrator: input resistor R into the inverting input, feedback capacitor C.

    Gc = Vc/Vo = 1/(sRC) = (1/ωRC) ∠90°
    Type II — one pole at origin + one zero + one pole
    Gc2(s) = GM1+ωz/s1+s/ωp

    GM = R₂/R₁ is the mid-band gain. Bode magnitude: falls from a pole at origin, flattens between ωz and ωp, then falls again.

    Type III — two zeros, one pole at origin + two poles

    Gc(s) = k (1+s/ωz1)(1+s/ωz2)s(1+s/ωp1)(1+s/ωp2)

    Type II and III compensators are typically built into the switching-supply's error amplifier directly. The controller error amplifier block inside a real converter takes Vo and Vref as inputs and outputs Vc, which drives the PWM comparator against a ramp to set the duty cycle.

    07

    Frequency Response & Stability

    GM · PM

    Two numbers describe how close a closed-loop converter sits to instability: Gain Margin (GM) and Phase Margin (PM).

    Gain margin procedure
    1. Find ωgm where loop phase = −180° (the gain-margin frequency)
    2. Determine the loop gain |L(jωgm)| at that frequency
    3. GM is the gain required to raise the magnitude curve back up to 0 dB
    Phase margin procedure
    1. Find ωpm where loop gain = 0 dB (the gain-crossover frequency)
    2. PM is the difference between the loop phase at ωpm and −180°
    GM < 0 ⇒ unstablea negative gain margin means a compensator must be (re)designed to fix it

    Worked example

    A Type-3 system with:

    L(jω) = 1000(jω+4)(jω+8)(jω+10)

    Phase margin

    Set |L(jω)| = 1:   1000 / [√(ω²+16)·√(ω²+64)·√(ω²+100)] = 1
    ⇒ ωpm = 6.79 rad/s  (gain crossover frequency)

    ∠L(jωpm) = −tan⁻¹(ωpm/4) − tan⁻¹(ωpm/8) − tan⁻¹(ωpm/10) = −134°
    PM = 180° + (−134°)
    PM = 46°positive → stable

    Gain margin

    Set ∠L(jω) = −180°:   −tan⁻¹(ω/4) − tan⁻¹(ω/8) − tan⁻¹(ω/10) = −180°
    ⇒ ωgm = 12.33 rad/s  (phase crossover frequency)

    |L(jωgm)| = 1000 / [√(ωgm²+16)·√(ωgm²+64)·√(ωgm²+100)] = 0.3307
    GM = 1/|L(jωgm)| = 3.024  ⇒  GM(dB) = −20·log₁₀(0.3307)
    GM = 9.61 dBstable
    Reading the plant into the loop

    In a real converter, the loop is: Vref → error amplifier (compensator) → Vc → PWM → d → switch → load → Vo, fed back to the error amplifier's inverting input. GM and PM are evaluated on the total loop gain L(jω) = (compensator)×(plant), which is why compensator design (Module 6) and frequency-response analysis are studied together.

    08

    Voltage vs Current Mode Control

    Dr. Ankur · 9 Sep
    Voltage mode control

    A single voltage-loop compensator compares Vo to Vref, and its output Vc is compared to a fixed ramp inside the PWM to set duty cycle d. Simple, single feedback loop.

    Current mode control

    Adds an inner current loop (sensing inductor current via Ki) inside the outer voltage loop (sensing Vo via Kv). The current-loop compensator output is compared against the sensed current ramp; the voltage-loop compensator sets the current reference. Two compensators in cascade — current loop compensator (inner) and voltage loop compensator (outer).

    Classification of current-mode control

    A · Fixed frequency
    1. Peak Current Mode Control (PCMC)
    2. Valley Current Mode Control (VCMC)
    3. Emulated Current Mode Control (ECMC)
    4. Average Current Mode Control (ACMC)
    B · Variable frequency
    1. Hysteretic Current Mode Control (HCMC)

    1 · Peak Current Mode Control (PCMC)

    A fixed-frequency scheme. It senses the peak inductor current while the power switch is on, then uses it to turn the switch off once iL crosses the control/reference level.

    2 · Valley Current Mode Control (VCMC)

    Senses the valley inductor current while the switch is off, and uses it to turn the switch on.

    TraitNote
    Subharmonic oscillationOccurs at duty cycle < 50%
    ResponseSlower response to sudden input-voltage changes

    3 · Emulated Current Mode Control (ECMC)

    Combines VCMC's ability to operate at very low duty cycles with PCMC's quick response to sudden line/load changes. ECMC samples the valley inductor current, then uses it to emulate the inductor current's up-slope; this emulated current provides the peak-current information needed to turn the switch off.

    Caveat

    ECMC suffers from sub-harmonic oscillation at duty cycles > 50%, requiring a compensation ramp with a slope greater than half the sum of the inductor's up-slope and down-slope to damp it. It also has a minimum on-time limit due to the delay needed to properly sense the peak current.

    4 · Average Current Mode Control (ACMC)

    • Good dynamic response
    • Easy to implement

    Instead of reacting to a single instantaneous sample, the compensator tracks the average inductor current continuously.

    B · Hysteretic Current Mode Control (HCMC)

    • Senses both the valley and the peak inductor current, using them to turn the switch on and off
    • Does not suffer from sub-harmonic oscillation or minimum/maximum duty-cycle limitations
    • Variable switching frequency (unlike the four fixed-frequency schemes above)
    Current-mode control scheme comparison

    Voltage Sag (Dip)

    Temporary reduction in RMS voltage magnitude between 0.1 and 0.9 pu, lasting 0.5 cycles to 1 minute.

    Common causes: system faults (70–80% of sags), large motor starting, transformer energisation, heavy load switching.
    Effects: contactors/relays dropping out, VSD tripping, computer & PLC resets, lighting flicker.

    Voltage Swell

    Reciprocal of sag — temporary increase in RMS voltage above 1.1 pu, lasting 0.5 cycles to 1 minute.

    Common causes: sudden load reduction, single-line-to-ground faults, capacitor switching, voltage-regulator malfunction.
    Effects: insulation stress & breakdown, electronic component damage, premature equipment aging, motor overheating.

    Harmonics — the fundamentals

    Sinusoidal voltages or currents having frequencies that are integer multiples of the fundamental frequency.

    i(t) = I₁·sin(ωt+φ₁) + ∑h=2∞ Ih·sin(hωt+φh)h = harmonic order · Ih = h-th harmonic amplitude

    Common harmonic orders

    • Odd harmonics — 3rd, 5th, 7th, 11th, 13th … (most significant)
    • Even harmonics — generally small in balanced systems
    • Triplen harmonics — 3rd, 9th, 15th … (zero-sequence) — magnitude and angles are the same

    Sources of harmonics

    Non-linear loads
    • SMPS
    • VFD (variable frequency drives)
    • Rectifiers & converters
    • Arc furnaces
    • Welding equipment
    Power electronic devices
    • Inverters
    • UPS systems
    • Battery chargers
    • LED drivers
    • Solar inverters
    • EV chargers

    Key point: modern electronic equipment is both a source and a victim of harmonics.

    IEEE 519 limits

    • Voltage THD: < 5% at PCC (point of common coupling)
    • Current THD: varies with Isc/IL ratio
    • Individual harmonic: < 3% of the fundamental

    Effects of harmonics

    On electrical equipment
    • Transformer overheating
    • Motor torque pulsations & heating
    • Cable heating (skin effect)
    • Capacitor overloading
    • Neutral conductor overloading
    On the power system
    • Increased losses & reduced efficiency
    • Resonance conditions
    • Interference with communication systems

    THD, Power Factor & PFC

    Unit 2/3

    Distortion metrics

    Total Harmonic Distortion (THD)

    Ratio of the RMS value of the waveform not including the fundamental, to the fundamental.

    THDV = √(∑h=2∞ Vh²) / V₁ ×100%
    THDI = √(∑h=2∞ Ih²) / I₁ ×100%
    Total Demand Distortion (TDD)

    Like THDI, but normalised to the maximum demand load current IL instead of the fundamental — avoids overstating distortion at light load.

    TDD = √(∑h=2∞ Ih²) / IL ×100%
    Individual Harmonic Distortion (IHD)
    IHDh = (Ih/I₁) ×100%

    Measurement equipment: power quality analysers, spectrum analysers, oscilloscopes with FFT, digital multimeters (true RMS), harmonic analysers.

    Power factor

    PF = P/S = cosφP = real power (W) · S = apparent power (VA) = Vrms×Irms · φ = phase angle between V and I
    PFCategoryLoad typeCurrent
    PF = 1UnityResistiveIn phase with V
    PF < 1 (lag)InductiveMotors, transformersLags voltage
    PF < 1 (lead)CapacitiveCapacitor banksLeads voltage
    Why low PF matters

    Low PF means higher current for the same real power — leading to increased I²R losses and reduced system efficiency.

    10 kW load, V=220V:   PF=0.5 ⇒ I = 10000/(220×0.5) = 87 A  ·  PF=0.9 ⇒ I = 10000/(220×0.9) = 48 A
    Current reduction: 45%

    Power factor correction (PFC)

    Passive PFC — fixed shunt capacitor

    A capacitor in parallel with the (inductive) load provides leading current that compensates the lagging inductive current, reducing net reactive power.

    Qc = P(tanφ₁ − tanφ₂)
    C = Qc / (2πfV²)

    φ₁ = initial angle, φ₂ = desired angle.

    Automatic PFC

    A PF controller/relay senses V/I via sensors and current transformers, computes PF, and switches a capacitor bank in/out through a microcontroller-driven relay system to track load changes.

    Active PFC — the boost converter

    • Switch S controls inductor current
    • Current shaping forces iin to follow the AC voltage waveform
    • High-frequency switching (20–100 kHz), fsw ≫ fline
    • Feedback control maintains the DC output

    The boost stage's switching waveforms show VL=|Vs|=Vd while S is on (iL ramps up), and VL=|Vs|−Vo while S is off (iL ramps down with negative slope near the line peak) — the envelope of the switching-frequency triangle wave tracks the rectified sine, giving a near-sinusoidal averaged input current.

    Active PFC control methods

    MethodTraits
    Average current mode controlCurrent loop shapes input current; voltage loop regulates output; good dynamic response
    Peak current mode controlSimpler implementation; faster transient response; may require slope compensation
    Hysteresis controlVariable-frequency operation; simple analog implementation; good current tracking
    Digital controlMicrocontroller/DSP-based; advanced algorithms

    Power factor vs. displacement power factor

    • DPF (Displacement Power Factor) = cosφ₁, where φ₁ is the fundamental phase angle
    • True power factor includes harmonic effects: PF = Ptotal/(VrmsIrms)
    PF = DPF × 1/√(1+THDI²)
    Example

    A load with DPF=0.95 and THDI=30%:
    PF = 0.95 × 1/√(1+0.3²) = 0.95×0.958 = 0.91
